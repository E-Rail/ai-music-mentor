# AI 音乐导师

弹一段钢琴，它会告诉你**实际弹出来的**是什么，而不是你本该弹什么。

音符错了、节奏赶了、两只手没对齐 —— 每一条结论都指回谱面上的那一拍。

## 怎么用

1. **选一首曲子**：内置《小星星》《两只老虎》《欢乐颂》《茉莉花》，也可以上传 MusicXML / MIDI，或者直接拍一张谱子的照片。
2. **选一个输入方式**：
   - **MIDI 键盘** —— 最准。插上 USB MIDI 琴，在 Chrome 或 Edge 里打开。
   - **麦克风** —— 什么琴都行，真钢琴也行。首次录音前会加载一次听音模型。
3. **弹**。光标跟着**你弹的音**走，不是跟着谱子走；你什么时候开始，拍子就什么时候起。
4. **看诊断**：哪几个音、错在哪、然后给你一条针对性的练习。

## 需要什么

- **Chrome 或 Edge**。MIDI 键盘用的是 Web MIDI，Safari 和 Firefox 还不支持。麦克风路径在所有现代浏览器上都能用。
- **麦克风或 MIDI 权限**：浏览器会问一次,允许即可。
- 安静一点的环境。麦克风识别的是琴音，旁边说话会被当成音。

## 关于这个演示

这是单用户演示。练习记录存在容器里，Space 重启后会清空 —— 曲库、诊断、练习生成都不受影响，只是历史不留。

麦克风走 Onsets and Frames（能同时听出和弦与双手），MIDI 走键盘原始事件。文字讲解由大模型生成，但它只负责解释已经算好的数字，不负责判断对错。
